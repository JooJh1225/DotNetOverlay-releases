# DotNetOverlay (DNO) — 배포

iRacing 실시간 텔레메트리 오버레이. Windows 전용.

게임 위에 떠 있는 **입력 · 접근 · 델타 · Relative · Standings · 날씨 · 바람 · 스포터**
여덟 개의 창을 **리모컨** 하나로 켜고 끄고, 크기와 표시 요소까지 고릅니다.
.NET 설치는 필요 없습니다 — 자체 포함 빌드(win-x64)입니다.
