INPUT

APPROACH

DELTA

기준 랩 대비 왼쪽이 벌고 오른쪽이 잃습니다

RELATIVE

앞뒤 차와의 실시간 시간차와 랩 차이

STANDINGS

클래스별 순위 · ±iR 예상 · LAST 열

WEATHER

트랙 온도와 10분 추이, 대기 · 습도 · 기압 · 밀도

WIND

불어가는 방위로 섹터가 돌고, 아크 굵기가 풍속. 면이 없어 게임이 그대로 비칩니다

SPOTTER

옆 차를 좌우 레일에. 위치가 앞뒤, 길이가 겹침, 색이 위험도

설치

  1. 압축을 풉니다

    푼 폴더가 곧 설치 폴더입니다.

  2. 폴더째 두세요

    assets\, samples\, Fonts\ 를 실행 중에 읽습니다.

  3. SimRacingOverlay.exe 실행

    처음 켜면 리모컨만 뜹니다. 창은 상단 체크박스로 켜고, 리모컨을 닫으면 종료됩니다. 실행 파일과 설정 폴더 이름이 SimRacingOverlay 인 것은 옛 이름을 그대로 둔 것입니다 — 바꾸면 이미 맞춰 둔 창 배치가 초기화됩니다.

SmartScreen 경고

서명 인증서가 없어 "Windows가 PC를 보호했습니다"가 뜹니다. 추가 정보 → 실행.

certutil -hashfile DotNetOverlay-vX.Y.Z-win-x64.zip SHA256

요구 사항

OSWindows 10 / 11 (x64)
런타임불필요 — 자체 포함 빌드
iRacing 라이브Documents\iRacing\app.ini 에 irsdkEnableMem=1
텔레메트리 소스iRacing 라이브 · .ibt 재생 · 합성(Mock)
설정 저장%AppData%\SimRacingOverlay\settings.json
