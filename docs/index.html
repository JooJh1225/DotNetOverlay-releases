Eight windows여덟 개의 창

INPUT

Throttle · brake · clutch bars, input traces, steering wheel 스로틀 · 브레이크 · 클러치 바와 인풋 트레이스, 스티어링 휠

APPROACH

How close the car behind is, read from a single marker 뒤차가 얼마나 다가왔는지를 마커 위치 하나로

DELTA

Against a reference lap — left is gaining, right is losing 기준 랩 대비 왼쪽이 벌고 오른쪽이 잃습니다

RELATIVE

Live gaps to the cars ahead and behind, with lap difference 앞뒤 차와의 실시간 시간차와 랩 차이

STANDINGS

Class standings · projected ±iR · LAST column 클래스별 순위 · ±iR 예상 · LAST 열

WEATHER

Track temp with 10-minute trend, air · humidity · pressure · density 트랙 온도와 10분 추이, 대기 · 습도 · 기압 · 밀도

WIND

The sector rotates to the wind heading, arc width is speed. No backing — the game shows through 불어가는 방위로 섹터가 돌고, 아크 굵기가 풍속. 면이 없어 게임이 그대로 비칩니다

SPOTTER

Cars alongside on left and right rails — position is ahead/behind, length is overlap, color is danger 옆 차를 좌우 레일에. 위치가 앞뒤, 길이가 겹침, 색이 위험도
